Basics
=======

AutoModel
---------

Useful args:

  - ``disable_update=True``
  - ``log_level=info``
  - ``hub=hf``, ``hub=ms``, ``hub=modelscope``, ``hub=huggingface``
  - ``model_revision=master``
  - ``model_path=/path/to/my-model-dir`` to use the model from a local directory
  - ``sed=0``, for python random, numpy, torch
  - ``device='cpu'``, ``device=cuda:0``
  - ``batch_size=1``
  - ``ncpu=1``
  - ``disable_pbar=True``

- configuration.json
- config.yaml, model.pt
