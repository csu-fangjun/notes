macos
=====

VLC is installed in ``/Applications/VLC.app``.

 - ``/Applications/VLC.app/Contents/MacOS/include/vlc/libvlc.h``
 - ``/Applications/VLC.app/Contents/MacOS/include/vlc/vlc.h``
 - ``/Applications/VLC.app/Contents/MacOS/lib/libvlc.dylib``

API doc `<https://videolan.videolan.me/vlc/group__libvlc__core.html>`_
