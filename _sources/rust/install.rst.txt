Install
=======

.. code-block:: bash

   rustc --version

.. code-block:: bash

  rustc 1.74.0 (79e9716c9 2023-11-13)

.. code-block:: bash

   cargo --version

.. code-block:: bash

  cargo 1.74.0 (ecb9851af 2023-10-18)

.. code-block:: bash

   # install the latest version
   rustup update

after update, ``rustc --version`` prints ``rustc 1.87.0 (17067e9ac 2025-05-09)``
and ``cargo --version`` prints ``cargo 1.87.0 (99624be96 2025-05-06)``.
