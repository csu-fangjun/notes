``Small-footprint keyword spotting using deep neural networks`` :cite:p:`chen2014small`
is the first paper using DNN for KWS.

``Convolutional neural networks for small-footprint keyword spotting`` :cite:p:`sainath2015convolutional`
replaces DNN with CNN to reduce computation overhead and number of parameters.
