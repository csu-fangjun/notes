npm install -g yo
npm install -g generator-napi-module

mkdir first
cd first
yo napi-module
npm test

To install node-gyp:

npm install node-gyp

You will find the executable inside ./node_modules/.bin/node-gyp.

You can run:

./node_modules/.bin/node-gyp configure
./node_modules/.bin/node-gyp build
